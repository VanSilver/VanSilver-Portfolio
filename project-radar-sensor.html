Radar Sensor
Wireless Human Presence Sensor

This project implements a human presence sensor that communicates wirelessly with the Smart Stair Light controller, utilizing advanced Hi-Link radar technology.

Key Features:
• Highly sensitive human motion and presence detection.
• Sends wireless control signals directly to the Smart Stair Light system.
• Built-in Web Server for configuring advanced sensor parameters in real-time.

Technology & Engineering:
ESP Microcontrollers HLK-LD2420 HLK-LD6002B Web Server
